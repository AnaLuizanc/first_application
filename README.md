# First Application

Um aplicativo Flutter demonstrativo com navegação múltipla.

## Sobre o Projeto

Este aplicativo demonstra a implementação de um layout simples com múltiplas formas de navegação, incluindo:

- Bottom Navigation Bar para navegação rápida entre telas principais
- Drawer (menu lateral) para acesso a todas as páginas
- Três telas principais:
  - Home: Tela inicial com ícone de boas-vindas
  - Página 1: Demonstração de conteúdo com ícone e texto explicativo
  - Página 2: Página de viagens com layout informativo

## Funcionalidades

- Navegação fluida entre telas
- Interface consistente com tema personalizado
- Drawer sincronizado com a Bottom Navigation Bar
- Design responsivo e moderno

## Estrutura do Projeto

O projeto está organizado da seguinte forma:

- `lib/main.dart`: Ponto de entrada do aplicativo
- `lib/homePage.dart`: Implementação principal da interface e navegação

## Como Executar

1. Certifique-se de ter o Flutter instalado em sua máquina
2. Clone este repositório
3. Execute `flutter pub get` para instalar as dependências
4. Execute `flutter run` para iniciar o aplicativo
